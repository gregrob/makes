# makes

Personal collection of 3D designs, CAD files, and fabrication projects.

## Structure

Each project lives in its own folder:

```
project-name/
├── fusion/    # Fusion 360 source files (.f3d)
├── step/      # STEP exports for use in other CAD tools
└── bambu/     # Bambu Studio slicer projects (.3mf)
```

## Projects

| Project | Description |
|---|---|
| `ms01-1u-psu-mount` | 1U rack mount PSU holder for Minisforum MS-01 - can mount up to 4 PSU's in a ms-01 cluster |
